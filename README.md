# DeskPet 桌宠 —— 桌宠形象修改分支

本分支专门用于**桌宠形象修改**（卡比形象迭代）。

## 形象改动内容

- 卡比形象：粉球身体、两只小手、大脚、竖长黑眼（眼球跟随鼠标）、小嘴
- 眨眼动画：3 秒周期、每次眨眼 300ms
- 互动：眼球跟随鼠标（最大 4px 偏移）
- 张嘴互动：鼠标离桌宠越近，嘴张得越大（60px 内最大、350px 外闭嘴，逐帧平滑过渡）

## 说明

- 形象绘制代码在 `app/pet.py` 的 `_draw_placeholder`（200px 基准坐标 + 缩放）
- 修改形象时参考该函数内的坐标与颜色常量
- Everything 搜索等功能见其他分支（f1）
